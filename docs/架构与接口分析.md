## 5. 架构观察

1. **分层清晰**：页面 chunk（`XxxPage`，`default` 导出 Vue 组件）— 共享 API 客户端 chunk（`ticket`/`campaign`/`rating`/`voices`/`museum`/`dorm`/`debate`/`tally`/`grade`/`file`）— 入口运行时（`index`，导出 `createVNode`/`ref`/`useRouter` 等 60+ 辅助）— 布局组件（`PageHeader` 等）。
2. **实时能力**：`useTallySocket`（唱票实时刷新）、`useDebateSocket`（辩论赛实时投票）走 WebSocket，与 REST 并行。
3. **账号体系双轨**：短信验证码（`/sms`）与 QQ OAuth（`/auth/qq-*` + `/user/bind-qq`）并存，支持 QQ 音乐扫码授权（`/qqmusic`）。
4. **权限**：`/permissions/my`、`/admin/*` 后台、路由级 `requiresAuth`（49/72 需登录）。
5. **万能墙**：`WallPage` 独立功能域（校园匿名/公开墙）。
